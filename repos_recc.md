# Repository Recommendations

## 1. learn2branch-ecole — Recommended starting point
https://github.com/ds4dm/learn2branch-ecole

Modern PyTorch, PyTorch Geometric, and Ecole implementation of the bipartite GCNN branching policy. Use this as the main project base.

## 2. learn2branch — Original implementation
https://github.com/ds4dm/learn2branch

Official NeurIPS 2019 implementation. Use it for reference and comparison with the original experiments.

## 3. branch2learn — Additional reference
https://github.com/Sandbergo/branch2learn

Ecole-based GNN branching implementation with dataset generation, training, testing, and evaluation examples.

## Recommended usage

Start with `learn2branch-ecole`, refer to `learn2branch` for reproduction details, and use `branch2learn` for additional implementation ideas.
